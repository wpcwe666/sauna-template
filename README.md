# Шаблон сайта сауны/бани — с админкой и бронированием в Telegram

Одностраничный сайт сауны, который продаётся владельцам бань и саун. Покупатель
не касается кода: разворачивает сайт кнопкой, заходит в админку `/admin`,
заполняет форму своими данными — сайт обновляется сам. Заявка на бронь уходит
готовым человеческим сообщением менеджеру в Telegram.

---

## 1. Путь клиента: три шага

**Шаг 1. Развернуть сайт.** На странице шаблона нажать кнопку
«Deploy to Netlify» (раздел «Кнопка деплоя» ниже). Понадобится бесплатный
аккаунт Netlify, сайт получит адрес вида `имя.netlify.app`. Свой домен
подключается в настройках Netlify (Domains → Add domain).

**Шаг 2. Включить админку (один раз).**
1. В панели Netlify открыть сайт → **Integrations → Netlify Identity → Enable Identity**.
2. В настройках Identity: **Registration → Invite only**.
3. **Invite users** — ввести свою почту, придёт письмо, задать пароль по ссылке.
4. Там же: **Identity → Services → Git Gateway → Enable Git Gateway**.

**Шаг 3. Заполнить свой контент.** Зайти на `ваш-сайт.netlify.app/admin`,
войти по почте и паролю, заполнить форму:

| Блок | Что редактируется |
|---|---|
| Название, слоган, адрес, телефон | Первая секция формы |
| Telegram менеджера | Юзернейм без @ — сюда приходят заявки |
| Группа ВКонтакте | Ссылка |
| Часы работы | Открытие и закрытие; если работаете после полуночи — закрытие меньше открытия (например 03:00) |
| Максимум гостей, приближение карты | Числа |
| Залы и цены | Название зала, цена за час, описание |
| Дополнительные услуги | Название и цена за визит («Банное меню») |
| Особенности | Строки — иконки подберутся по смыслу |
| Фотографии | Загрузка прямо из админки; первое фото — главное (шапка + соцсети) |

Кнопка **Publish** — сайт обновляется через минуту-две автоматически
(вместе с ним обновляются заголовок, описание и разметка для поисковиков).

## 2. Кнопка деплоя (для продавца шаблона)

Когда шаблон загружен в ваш репозиторий GitHub, вставьте в любое место
(лендинг, письмо клиенту) кнопку, заменив `ВАШ_ЛОГИН/РЕПОЗИТОРИЙ`:

```markdown
[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/ВАШ_ЛОГИН/РЕПОЗИТОРИЙ)
```

Клиент нажимает → Netlify копирует шаблон в его аккаунт → сайт работает.
Дальше шаги 2–3 выше.

## 3. Как это устроено (для поддержки)

- **Контент живёт в `content.json`** — его читает сайт при загрузке.
  Админка (Decap CMS, русский интерфейс) правит только этот файл и папку `images/`.
- **`build.js`** запускается при каждом деплое (см. `netlify.toml`): подставляет
  название, слоган, цены, телефон и адрес в `<title>`, meta description,
  Open Graph и JSON-LD — поисковики видят реальный контент.
- **Фолбэк:** если `content.json` недоступен (например, `index.html` открыли
  как файл без сервера), сайт показывает значения из встроенного блока `CONFIG`
  внутри `index.html`. На хостинге всегда работает `content.json`.
- Смена через полночь поддерживается: часы «12:00–03:00» дают слоты до 03:00.
- Фавиконка — SVG-монограмма, буква берётся из названия автоматически.

## 4. Продвинутый путь: правка руками

Можно вообще не пользоваться админкой: открыть `index.html`, найти блок
`CONFIG` (помечен комментарием «ЗАМЕНИТЕ ЗНАЧЕНИЯ НА СВОИ») и вписать значения.
Формат полей — тот же, что в `content.json`. После правок проверьте `<head>`
(title, description, OG, JSON-LD) — вручную, или просто положите рядом правленый
`content.json` и дайте Netlify собрать: `build.js` сделает это сам.

## 5. Фото

- Подойдут горизонтальные кадры 1600×1200 или больше, JPG до ~300 КБ.
  Админка ограничивает размер файла 4 МБ.
- Первое фото (`photos[0]`) — главное: оно стоит в герое и уходит в `og:image`.
- Если какого-то файла нет, на его месте — аккуратная заглушка
  «Фото добавит владелец», сайт не выглядит сломанным.

## 6. Проверка перед передачей клиенту

- Заявка доходит до нужного Telegram: подставьте юзернейм и отправьте тестовую
  заявку. Если Telegram не открылся — появится окно с текстом заявки и кнопкой
  «Скопировать» (резервный путь).
- Зайти в `/admin`: форма открывается, правки публикуются, сайт обновляется.
- Открыть сайт с телефона: шапка, форма брони и читаемость текстов.

## 7. Хостинг

Основной вариант — Netlify (кнопка деплоя, админка и Identity встроены).
Подойдёт любой статический хостинг: GitHub Pages, Vercel, обычный хостинг —
это папка статики: `index.html`, `content.json`, `images/`, `admin/`, `build.js`,
`netlify.toml`. Без Netlify админка потребует альтернативной настройки входа
(см. документацию Decap CMS: backend `github` или `git-gateway`).

## Файлы

- `index.html` — весь сайт (стили, скрипты, шрифты Podkova/Golos Text и знак ₽ встроены).
- `content.json` — контент сайта; редактируется админкой.
- `admin/` — админка (Decap CMS): страница входа и описание полей формы.
- `build.js` — подстановка контента в SEO-теги при деплое.
- `netlify.toml` — настройки сборки и заголовков кэша для Netlify.
- `images/` — фотографии.
- `RESEARCH.md` — исследование 33 сайтов саун (дизайн-обоснование).
- `DESIGN.md`, `PRODUCT.md`, `.impeccable/` — служебные файлы дизайн-процесса.
