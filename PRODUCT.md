# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static single-file `index.html` (inline CSS/JS), no frameworks, no external libraries — decided explicitly by the client brief. Deploy target: GitHub Pages / Netlify.

## Users

Гости сауны: компании друзей, семьи, небольшие корпоративные компании, планирующие сеанс (парная, купель/бассейн, зона отдыха). Смотрят сайт с телефона чаще всего, решают быстро (вечер, выходные, спонтанная компания). Задача: понять, что за баня, сколько стоит, свободно ли в принципе их слот, и отправить заявку менеджеру.

## Product Purpose

Одностраничный сайт сауны (финская сауна, спа-формат). Две работы: (1) убедить, что эта сауна подходит, (2) собрать бронь и отправить готовым человеческим сообщением менеджеру в Telegram. Успех = отправленная заявка, из которой менеджер сразу видит дату, время, гостей, зал, допы, имя, телефон.

## Positioning

Бронирование без звонка и без бэкенда: посетитель собирает визит на сайте, сайт формирует живой человеческий текст (с правильными склонениями, датой словами), открывает Telegram с предзаполненным сообщением. Наличие времени подтверждает администратор — сайт не делает вид, что он онлайн-табло. Итерация 2: визуальный мир «Номерок» заменён на «Табло сеансов». Итерация 3 (редизайн «Сруб и жар» по исследованию 33 сайтов). Итерация 4: сайт — продаваемый шаблон для владельцев бань и саун (аудитория не техническая): контент вынесен в content.json, редактируется онлайн-админкой /admin (Decap CMS, русский интерфейс) без кода; встроенный в index.html CONFIG — фолбэк для работы без сервера.

## Operating Context

Работает менеджер/администратор: получает заявку в Telegram, подтверждает вручную. Сайт живёт как статика (GitHub Pages / Netlify). Владелец сам заменяет CONFIG (название, адрес, телефон, Telegram, часы, залы, услуги) и кладёт фото в images/. Тестовый Telegram-аккаунт клиента: whynotonlyme.

## Capabilities and Constraints

- Сайт: один файл index.html, инлайн CSS/JS, никаких внешних библиотек; вес без картинок < 300 КБ. Шаблонный комплект: content.json (контент, правится админкой), admin/ (Decap CMS, вход через Netlify Identity), build.js (подстановка контента в title/description/OG/JSON-LD при деплое), netlify.toml. Часы работы поддерживают смену через полночь («12:00–03:00»).
- Mobile-first, 360–1920, все цели касания ≥ 44px.
- Виджет брони: календарь без прошлых дней; слоты начала по часам от hours.from до hours.to; длительность 1–4 ч, слоты, не влезающие до закрытия, недоступны; гости 1…capacity; зал — селект (один зал — зафиксирован); допы — чекбоксы; телефон РФ обязателен с маской/валидацией; живая ориентировочная стоимость.
- Сообщение менеджеру: обычный текст, без эмодзи, без markdown, без списков; порядок приветствие→что бронируют→дата словами («12 октября»)→время («с 12:00 до 16:00»)→гости со склонением («на 5 человек»)→зал→допы→имя и телефон→вежливый вопрос; fallback через 1,5 с — модалка с копированием и ссылкой на web.telegram.org.
- Открытие: https://t.me/<username>?text=<encodeURIComponent(сообщение)>.
- SEO: title, description, Open Graph, JSON-LD LocalBusiness, lang="ru", UTF-8; фавиконка — SVG-монограмма, не эмодзи.
- Hard bans: эмодзи нигде (кнопки, заголовки, favicon, aria-label, шаблон сообщения); сине-фиолетовые градиенты; glassmorphism; неон; Tailwind-дефолтная палитра; одинаковые карточки в 3 колонки; lorem ipsum; выдуманные фото.
- Фото не выдумывать: CONFIG.photos указывает на images/*.jpg — файлов нет до передачи владельцем; нет фото → аккуратный цветной блок с подписью «фото добавит владелец».
- Иконки — только инлайн SVG, линейный стиль (Lucide/Feather), один набор на весь сайт.

## Brand Commitments

Имя, адрес, телефон, Telegram-юзернейм, VK, часы, залы и услуги в брифе — шаблонные заглушки ({{…}}). До подстановки владельцем используются демо-значения, помеченные в коде как CONFIG — это допущение, не факт о бизнесе. Тон текстов: живой, человеческий, без канцелярита и «ИИ-интонации».

## Evidence on Hand

Нет. Настоящих фото, логотипа, отзывов нет. Не фабриковать: ни фото, ни отзывы, ни «кейсы». Всё содержимое — из CONFIG или честные подписи-заглушки.

## Product Principles

1. Заявка — продукт: виджет центральный, всё остальное ведёт к нему.
2. Честность: сайт подтверждает, а не обещает — «наличие времени подтверждает администратор».
3. Тепло без самодеятельности: язык живой, дизайн взрослый, без эмодзи и клише.
4. Одно касание: любая цель на телефоне ≥ 44px, бронь — за минуту.

## Accessibility & Inclusion

Контраст текста ≥ 4.5:1 (крупный ≥ 3:1), фокус видим, все контролы доступны с клавиатуры, label у каждого поля, aria-live для расчёта стоимости, лайтбокс закрывается Esc.
